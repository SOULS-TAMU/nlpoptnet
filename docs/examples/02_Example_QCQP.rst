Quadratically Constrained Quadratic Programs (QCQPs)
====================================================

Consider the following QCQP problem:

.. math::

   \begin{aligned}
   \min_{y} \quad & \frac{1}{2} y^\top Q y + c^\top y \\
   \text{s.t.} \quad
   & A y = b + B x, \\
   & y^\top C_i y + d_i^\top y \leq \beta_i + E_i x, \quad i = 1, 2, \ldots, m_i, \\
   & l + L x \leq y \leq u + U x.
   \end{aligned}

where, :math:`Q \in \mathbb{R}^{n \times n} \succeq 0`, :math:`c \in \mathbb{R}^n`, :math:`A \in \mathbb{R}^{n_{\mathrm{eq}} \times n}`, :math:`b \in \mathbb{R}^{n_{\mathrm{eq}}}`, :math:`B \in \mathbb{R}^{n_{\mathrm{eq}} \times p }`, :math:`C_i \in \mathbb{R}^{n \times n} \succeq 0`, :math:`d_i \in \mathbb{R}^n`, :math:`\beta_i \in \mathbb{R}`, :math:`E_i \in \mathbb{R}^{1 \times p}` for :math:`i = 1, 2, \ldots, n_{\mathrm{ineq}}`, :math:`l \in \mathbb{R}^n`, :math:`L \in \mathbb{R}^{n \times p}`, :math:`u \in \mathbb{R}^n`, and :math:`U \in \mathbb{R}^{n \times p}`. We must learn to approximate the optimal solution :math:`y \in \mathbb{R}^n` given a parameter realization :math:`x \in \mathbb{R}^p`. For this example consider, :math:`n=10, p=5,n_\textrm{eq}=5,n_\textrm{ineq}=5`.

Define the objective, constraints, and the parameter sample space
-----------------------------------------------------------------

.. code-block:: python

   model.objective(0.5 * model.quad(model.Q, y) + model.lin(model.c, y))
   model.constraints.equality.add(model.lin(model.A, y) == model.b + model.lin(model.B, x))
   model.constraints.inequality.add(model.batch_quad(model.Cq, y) + model.batch_lin(model.dq, y) <= model.beta + model.batch_lin(model.E, x))
   model.constraints.box.add(var=y, lower=model.l + model.lin(model.L, x), upper=model.u + model.lin(model.U, x))

   model.box(lower=np.array([-1.0]*5), upper=np.array([1.0]*5), num_samples=200)
