TITLE: Uniform Sampling from a Simplex or Polytope

--------------------------------------------------
1. IMPORTANT CHECK
--------------------------------------------------

If your region is defined as:

    M x <= 0

then this is typically an UNBOUNDED cone.

→ You CANNOT sample uniformly from an unbounded region.

To make it a bounded simplex/polytope, you must add constraints like:

    sum(x) = 1
    x >= 0

or more generally:

    A x <= b
    C x = d


--------------------------------------------------
2. CASE 1: SIMPLEX GIVEN BY VERTICES (BEST METHOD)
--------------------------------------------------

If your simplex is defined by vertices:

    S = conv{v0, v1, ..., vn}

Then sample uniformly using barycentric coordinates:

Step 1:
    Sample weights:
        w ~ Dirichlet(1, 1, ..., 1)

Step 2:
    Compute:
        x = sum_i w_i * v_i

This gives EXACT uniform samples.

Implementation trick:
    Sample g_i ~ Exp(1)
    Then:
        w_i = g_i / sum_j g_j


--------------------------------------------------
3. CASE 2: STANDARD SIMPLEX
--------------------------------------------------

Equality simplex:

    x_i >= 0
    sum(x_i) = 1

→ Sample:
    x ~ Dirichlet(1, ..., 1)


Inequality simplex:

    x_i >= 0
    sum(x_i) <= 1

→ Sample:
    (w1, ..., wn, w_{n+1}) ~ Dirichlet(1, ..., 1)

    Then:
        x = (w1, ..., wn)


--------------------------------------------------
4. CASE 3: GENERAL POLYTOPE (Ax <= b)
--------------------------------------------------

If you only have inequality constraints:

    A x <= b

Use a Markov Chain method:

    HIT-AND-RUN SAMPLING

Algorithm:

1. Start from feasible point x0

2. For each iteration:
    a. Sample random direction u (unit vector)
    b. Find all t such that:
            x + t*u satisfies A(x + t*u) <= b
    c. This gives interval:
            [t_min, t_max]
    d. Sample:
            t ~ Uniform(t_min, t_max)
    e. Update:
            x ← x + t*u

3. After burn-in, samples are approximately uniform.


--------------------------------------------------
5. RECOMMENDED APPROACH
--------------------------------------------------

If dimension is small and vertices are available:
    → Use Dirichlet (exact and fast)

If only inequalities are available:
    → Use Hit-and-Run

If only Mx <= 0:
    → Add normalization constraint (e.g., sum(x)=1)


--------------------------------------------------
6. CONNECTION TO YOUR PROBLEM
--------------------------------------------------

Binary constraint:
    x ∈ {(0,0), (1,0), (0,1)}

This is equivalent to:
    vertices of a simplex

Pipeline:

    continuous x_c
        ↓
    project to simplex
        ↓
    select extreme point (argmax)
